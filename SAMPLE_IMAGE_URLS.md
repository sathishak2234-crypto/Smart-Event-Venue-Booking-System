# Sample Venue Images - Ready to Use!

## How to Use
1. Choose a venue from the list below
2. Copy the **Main Image URL** and **Thumbnail URL**
3. Go to: `http://localhost:5000/admin-images.html`
4. Paste the URLs
5. Click Save

## How to Get Custom URLs for Your Venues

### Method 1: From Google
1. Search: "wedding hall venue photo"
2. Right-click image
3. Choose "Copy image link"
4. Use that URL directly

### Method 2: From Unsplash
1. Go to: https://unsplash.com/
2. Search for venue type (e.g., "event hall")
3. Click image
4. Copy the direct link from URL bar
5. Modify URL to size you want:
   - Add `?w=800` for width
   - Add `&h=600` for height
   - Add `&fit=crop` to crop

### Method 3: From Pexels
1. Go to: https://pexels.com/
2. Search for venue photos
3. Right-click and get image URL

## Troubleshooting URLs

| Problem | Solution |
|---------|----------|
| Image not loading | Check URL is accessible (paste in browser) |
| Wrong image size | Add `?w=800&h=600` to URL |
| Image too blurry | Use higher resolution source |
| URL expired | Use different image source |

## Tips

- ✅ Always test URL in browser first
- ✅ Use HTTPS URLs (more reliable)
- ✅ Keep files under 2MB
- ✅ Use consistent image quality
- ✅ Backup original URLs
